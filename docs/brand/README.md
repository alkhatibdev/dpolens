# The DPOLens logo

The mark is four rounded corners, the corners of a viewfinder, framing two lines of text: a lens
on the exact words. Every file here is drawn from outlines, so none of them needs a font.

| File | For |
| --- | --- |
| `dpolens-logo.svg`, `dpolens-logo.png` | The logo on a light ground: the README, documentation, the dashboard |
| `dpolens-logo-on-dark.svg`, `dpolens-logo-on-dark.png` | The logo on a dark ground |
| `dpolens-logo-black.svg`, `dpolens-logo-white.svg` | The logo in one colour, for print, slides and stamps |
| `dpolens-mark.svg`, `dpolens-mark-on-dark.svg`, `dpolens-mark-black.svg`, `dpolens-mark-white.svg` | The mark alone |
| `dpolens-icon.svg`, `icon-192.png`, `icon-512.png` | The app icon: the mark on a green tile |
| `apple-touch-icon.png` | A phone's home screen, 180 pixels square |
| `favicon.svg`, `favicon.ico` | The browser tab. The SVG follows a light or dark browser, and the ICO is for older ones |
| `social-preview.png` | The card a link to the repository shows, 1280 by 640 |

| Short line | `#12784E` | `#6FD3A4` |

The brand green is `#12784E`, and the dark ground is `#0D3B2A`. The name is set in Figtree
ExtraBold, with its letters 2% closer together than the font sets them.

The mark's rounded square, repeated, is the pattern on the dashboard's green cards and on the
sign-in pages, where it grows slowly from a corner. Its corner keeps the mark's proportion.

## Using it

- Leave clear space around the mark of at least the length of one corner's arm.
- Keep each corner its own colour, the mark upright, and the long line above the short one.
- Below 24 pixels, use the icon on its tile rather than the bare mark.
